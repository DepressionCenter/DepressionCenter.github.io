Mobile Technologies Core SharePoint Site View Formatting

Description

MTC SharePoint Site is an open-source collection of SharePoint Online JSON formatting examples for research operations. It includes reusable list, view, column, and form-header formats for contacts, study status, study timelines, workflow stages, ORCID links, Michigan Experts profiles, and study notebooks.

Copy a JSON file into the corresponding SharePoint formatting editor, then update field names and URLs for your site. The examples help Microsoft 365 teams create clearer research-tracking interfaces without building a custom SharePoint Framework (SPFx) web part.

Quick Start Guide

  • Open the appropriate .json file and copy its contents.
  • In your SharePoint library, go to the view, format view, advanced, and paste the JSON code.
  • Change the column names to match the column names in your list.
